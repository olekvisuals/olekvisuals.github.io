HOW TO OPEN
Double-click index.html. For full browser compatibility with local files, you can also serve the folder with any simple local web server.

HOW TO PUBLISH FOR FREE (GitHub Pages)
1. Create a GitHub account and a new public repository.
2. Upload the CONTENTS of this folder to the repository root.
3. Repository Settings → Pages → Deploy from a branch → main / root.
4. GitHub will provide your public address.

CONTACT / SOCIALS
These are deliberately left as a tasteful placeholder until you choose what should be public.

RECOMMENDED CLEAN GITHUB ADDRESS
If your GitHub username is, for example, olekvisuals:
- create the repository: olekvisuals.github.io
- upload the CONTENTS of this folder to the repository root
- publish from: main / (root)
Your address will then be:
https://olekvisuals.github.io
